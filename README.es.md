## Perfil profesional

Desarrollador Full Stack con alrededor de 2 años de experiencia construyendo aplicaciones web mantenibles, APIs REST y sistemas backend estructurados.

El stack principal está enfocado en **Vue**, **TypeScript**, **Python**, **Django**, **Django REST Framework** y **PostgreSQL**, con atención al código limpio, la arquitectura práctica y el modelado de datos escalable.

La experiencia incluye desarrollo frontend, diseño backend, desarrollo de APIs, bases de datos relacionales y entornos de desarrollo basados en Docker.
