## Sobre mí

Soy **Desarrollador Full Stack** con alrededor de 2 años de experiencia construyendo aplicaciones web con una estructura clara, mantenible y escalable.

Mi stack principal está centrado en **Vue**, **TypeScript**, **Python**, **Django**, **Django REST Framework** y **PostgreSQL**. Disfruto trabajar tanto en frontend como en backend, con especial interés en el diseño de APIs REST, arquitectura backend, modelado de bases de datos y desarrollo frontend moderno.

Aplico buenas prácticas como **TDD**, **SOLID**, **DDD**, **CQRS** y **Clean Architecture** cuando el proyecto lo requiere, buscando siempre código legible, responsabilidades bien definidas y soluciones prácticas.
